# Mundus Lounge — Homepage Checklist

## Working agreement

- Work on one unchecked milestone at a time.
- Verify desktop and mobile behavior, build, lint, and typecheck before review.
- Mark a milestone complete only after user approval.
- Treat the supplied mockup as the component and layout reference; use real assets and verified business context only.

## Milestones

- [x] Technical foundation: Next.js App Router, TypeScript, Tailwind CSS, and ESLint
- [x] Visual foundation: shared palette, typography, spacing, container, and button tokens
- [x] Header and hero: responsive navigation, real shisha hero asset, approved copy, and CTA shell
- [x] Intro / brand story section
- [ ] Shisha, drinks, and food offering sections
- [ ] Image-led gallery / atmosphere section using approved real imagery
- [ ] Menu or category presentation, without unverified pricing
- [ ] Reviews / social-proof section, after verified source material is supplied
- [x] Reservation flow: intentionally out of scope for the initial visual landing page
- [ ] Footer: verified contact details, hours, social links, and legal content
- [ ] Homepage visual polish pass: responsive review, accessibility, imagery, and typography refinement
- [ ] Final production verification: build, lint, typecheck, metadata, and route behavior
